# DOOM Feature Branch Pack

A reconstructed, cumulative Git branch history for the available Python DOOM assignment versions.

- `python_doom_enhanced_assignment.py` — current game for the checked-out branch.
- `versions/` — preserved source snapshot for each available version from v2 through v22 (v18 was not available).
- `CHANGELOG.md` — branch map and GitHub instructions.

See `CHANGELOG.md` before pushing. This is a standalone repository bundle; its history may not share ancestry with an already existing GitHub repository.
